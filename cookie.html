洛谷 Cookie 快速获取

30 秒搞定 · 无需打开开发者工具

01 三步拿到你的 Cookie

① 登录洛谷（新窗口）

点击 luogu.com.cn 并登录你的账号。登录后保持在那个页面，别关。

② 安装「洛谷 Cookie 复制器」扩展（推荐，支持全部 Cookie）

⚠️ 洛谷把关键 Cookie（_uid / __client_id）标记为 HttpOnly，网页脚本（书签）读不到，只有扩展能一键复制全量。

安装步骤（一次约 1 分钟，之后永久可用）：

  1. 打开仓库 github.com/fensoge/luogu-trainer → 绿色 Code → Download ZIP → 解压
  2. Chrome / Edge 地址栏输入 chrome://extensions 回车 → 打开右上角「开发者模式」
  3. 点「加载已解压的扩展程序」→ 选择解压出的 extension 文件夹
  4. 工具栏出现 🐦 图标即安装成功（固定到工具栏更方便）

③ 在洛谷页面点扩展图标 → 回训练舱粘贴

在登录的洛谷页面，点工具栏的 🐦 图标 → 弹出「✅ 已复制 N 个 Cookie」。

然后回到 训练舱 → 高级设置 → 洛谷 Cookie 旁点「📋 从剪贴板粘贴」，搞定。

以后 Cookie 过期，重新登录洛谷 → 再点一下 🐦 图标 → 粘贴，30 秒搞定。

不想装扩展？试试备用方案（书签 / F12）

备用 A：书签小工具（只能复制部分 Cookie）

把下面的按钮拖到书签栏；在洛谷页面点书签。若弹窗提示「Cookie 不完整」，说明 _uid / __client_id 是 HttpOnly，需改用扩展或 F12。

🐦 复制洛谷 Cookie
拖到书签栏；拖不动就右键 → 「复制链接地址」→ 新建书签粘贴

备用 B：F12 手动复制（100% 完整）

洛谷页面按 F12 → Network → 刷新 → 点任意一条 luogu.com.cn 请求 → Request Headers 里找到 Cookie: 一行，整段复制。

🔒 安全说明：书签脚本只在你正在浏览的洛谷页面上运行，读取的是你自己浏览器的登录态，数据直接进剪贴板，不经过任何服务器、不上传任何人。Cookie 等同账号凭证，只填进你自己的训练舱设置（仅发往你自己的 Worker），不要发给别人。
