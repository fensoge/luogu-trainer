Cloudflare 免费代理 · 约 3 分钟 · 一次性配置

01 部署你的代理 Worker

1注册 / 登录 Cloudflare

打开 dash.cloudflare.com → 注册（邮箱即可，免费，无需绑卡）→ 登录。

2创建 Worker

左侧菜单 →「Workers & Pages」→「创建」→ 选「创建 Worker」。

名称随便填，比如 luogu-trainer-proxy → 点「部署」→ 进入代码编辑页。

3粘贴代理代码并重新部署

把编辑页里默认的示例代码全部删掉，点下面的按钮复制本项目的代理代码，粘贴进去 → 点「部署」：

4复制你的 Worker 地址

部署成功后，页面会显示你的专属地址，形如：https://luogu-trainer-proxy.你的用户名.workers.dev

点击地址右侧的复制按钮，复制整段地址（带 https:// 前缀）。

5回训练舱填地址

回到 训练舱 →「⚙ 高级设置」→ 把地址粘贴进「Worker 代理地址」→（代理方式保持「自动」即可）→ 点「网络自检」→ 看到 Worker: ✅ 就完成了。

💡 小提示：
· Worker 只做「转发 + 跨域」代理，不保存任何 Cookie；你的 Cookie 只发往你自己的 Worker，互不泄露
· 免费额度：每天 10 万次请求，个人刷题完全够用
· 以后想更新代码：Cloudflare 后台 → Workers → 你的 Worker → 编辑代码 → 部署
进阶：命令行部署（wrangler）

在项目目录执行：

npm i
npx wrangler login # 浏览器授权
npx wrangler deploy

若网络受限导致上传失败，可用 deploy.mjs 兜底（详见仓库 README）。
